# Job scout — gate

Every search and extract key present. Missing → Gaps, halt.
Load `job-profile/references/contracts/contract-geography.md`; it owns residence matching and the separation from authorization.

Drop when the posting cannot hire this seeker (first match): onsite or hybrid-without-remote place that matches no `location.search_in` entry (never under `worldwide`); printed work_model that does not intersect kit-true flags (unknown → not a drop; no kit-true flag → not a drop), or named onsite place with no shared work_model flag (no kit-true flag → not a drop); remote permitted candidate locations incompatible with residence, or a known unmet explicit authorization requirement per the geography contract; hire-from only in `location.exclude_hire_from`; salary currencies none of which are in `market_currencies`; frontmatter `company` slug (schema-dossier "Filename" rule) equal to a slug in `exclude_companies`. Drop a `jd_date` older than the kit `date_posted` window (`24_hours` 1 day, `week` 7, `month` 31; `all_time` or none true → no bound): the search-time date keep saw the card, this sees the page. Blank is not a drop. Never infer authorization or currency from a company or country name. Hire-from is printed location, `work_auth`, `hiring_route`, `eligibility_evidence`, or a title country tag — never the company's country.

Write `eligibility` once per row, from the same evidence: a geographic or explicit authorization incompatibility above fired → `incompatible`; residence matches the printed permitted candidate locations and no explicit authorization requirement remains unmet or unknown → `confirmed`; missing or unresolved hiring-location evidence, or an unresolved explicit authorization requirement → `unknown`. Apply the shared geography contract, never match from search markets, citizenship, timezone, or the company's country. Never write `confirmed` from `work_model: Remote` alone. The row carries `eligibility_evidence` as extracted; the gate never rewrites it.

An `incompatible` row leaves the persist set as a kit drop, except that an existing dossier for its normalized `url` is rewritten per `job-store/references/schemas/schema-dossier.md` "Re-run rules" so the stored row reads `incompatible`.
