Job Kit · Design System

Flat editorial console

Square corners, hairline rules, alpha-composited ink, one neutral action color.

Brand

Positioning, mascot, logo lockup, and the iconography contract.

Color

One ink hue at five opacities, three surface layers, muted semantic hues, and a Tokyo-Night chart ramp.

Typography

Three families, each with one job: Inter for UI, Space Mono for identifiers, Space Grotesk for the wordmark.

Layout

4px spacing base, radius 0 with three deliberate exceptions, and elevation reserved for the floating layer.

Components

Buttons, inputs, cards, badges, nav, table, and overlays — all Elevation-0 with the 1-pixel rule.
