Common errors

"only https URLs are supported"

Use an https:// link. Plain http, local files and other schemes are refused.

"the URL points to a private or local address"

The file must be reachable on the public internet. Links to private networks are refused.

"unsupported file type"

Only PDF and DOCX resumes are supported. Export other formats to PDF first.

"the file exceeds the 10 MB download limit" or "download timed out"

Reduce the file size, or host it somewhere that serves it faster.

A scanned resume shows no_text_layer

The file holds an image of text, which most applicant tracking systems cannot read. Export it from the original document instead.
