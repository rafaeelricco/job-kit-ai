Resume Check MCP server

Resume Check lets an AI assistant check a resume file before you apply. It finds the parsing risks a page view hides, and it turns the assistant's rubric ratings into a score with fixed arithmetic, so every assistant gets the same number.

Server https://r1cco.com/job-kit-ai/mcp
Streamable HTTP No sign-in Read-only tools Files not stored

Setup

General

Resume Check is a remote MCP server at the address above. It speaks Streamable HTTP and needs no authentication. All four tools are read-only and none of them acts on an account.

  • Scans accept PDF and DOCX files up to 10 MB, served from a public https link or attached in ChatGPT.
  • The server does not call an AI model. Your assistant reads the resume and rates it; Resume Check scans the file and computes the score.
  • Each client address may make 120 requests a minute and 8 at a time.

Clients that only support local servers can still connect through the mcp-remote bridge. See Others.

Claude

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it Resume Check, paste the server URL, and save.
  3. In a conversation, turn Resume Check on from the tools menu.

Custom connectors need a Claude plan that supports them. On Team and Enterprise plans, an owner adds the connector for the organization first.

Claude Code

terminal
claude mcp add --transport http resume-check https://r1cco.com/job-kit-ai/mcp

ChatGPT

  1. In Settings → Apps → Advanced settings, turn on Developer mode.
  2. Choose Create app, name it Resume Check, paste the server URL, and set authentication to No authentication.
  3. In a conversation, select Resume Check from the tools menu and attach your resume.

An attached file reaches scan_resume_file; a link reaches scan_resume_url. Both return the same report.

Codex

Add the server to ~/.codex/config.toml:

config.toml
[mcp_servers.resume-check]
url = "https://r1cco.com/job-kit-ai/mcp"

Cursor

Add the server to ~/.cursor/mcp.json, or to .cursor/mcp.json in a project:

mcp.json
{
  "mcpServers": {
    "resume-check": { "url": "https://r1cco.com/job-kit-ai/mcp" }
  }
}

Visual Studio Code

Add the server to .vscode/mcp.json, or run MCP: Add Server from the command palette:

mcp.json
{
  "servers": {
    "resume-check": { "type": "http", "url": "https://r1cco.com/job-kit-ai/mcp" }
  }
}

OpenAI Agents SDK

Connect from your own agent. The review agent in the Job Kit repository is a complete example with guardrails.

agent.py
from agents import Agent, Runner
from agents.mcp import MCPServerStreamableHttp

async with MCPServerStreamableHttp(params={"url": "https://r1cco.com/job-kit-ai/mcp"}) as server:
    agent = Agent(name="Reviewer", mcp_servers=[server],
                  instructions="Review the resume with the Resume Check tools.")
    result = await Runner.run(agent, "Scan https://r1cco.com/job-kit-ai/samples/clean.pdf")

Others

Any client that supports remote MCP servers over Streamable HTTP can use the server URL directly. For a client that only runs local servers, start the bridge as a stdio command:

terminal
npx -y mcp-remote https://r1cco.com/job-kit-ai/mcp

To inspect the tools yourself, run npx @modelcontextprotocol/inspector and connect to the server URL with the Streamable HTTP transport.

Tools

Every tool returns structured content that matches its output schema, plus the same data as JSON text.

ToolWhat it does
get_review_rubricReturns the Job Kit rubric: seven weighted criteria, the 0 to 4 rating scale, the rule that bullets in the two most recent roles weigh double, the blocking defects and their cap of 40, and posting alignment weights.
score_resume_reviewTurns ratings into a 0 to 100 score. Returns the weighted score, whether the blocking cap applied, how much of the rubric was assessed, and posting alignment when requirements are given.
scan_resume_urlDownloads a PDF or DOCX from a public https link and reports parsing risks: no text layer, hidden text, contact details only in a header or footer, broken or private-use characters, text boxes, tables, images and file size.
scan_resume_fileThe same scan for a resume attached in a ChatGPT conversation.

Sample resumes for trying the tools describe a fictional person: clean.pdf, scanned.pdf, header-contact.docx and hidden-text.docx.

Common use cases

Check a resume before applying

Find what an applicant tracking system may misread, before a recruiter sees it.

Example promptCheck my resume for parsing problems before I apply: https://r1cco.com/job-kit-ai/samples/header-contact.docx
Get a full scored review

The assistant reads the rubric, scans the file, rates each criterion and bullet, and asks Resume Check for the score.

Example promptReview my attached resume against the Resume Check rubric and give me the score and the three changes that matter most.
Score ratings you already have

Skip the scan and compute the score from your own ratings.

Example promptScore a resume review with positioning 3, skills 4, organization 3, visual 4, writing 3, parsing 4, and bullets: two recent bullets rated 4 and 3, one older bullet rated 2.
Fix a scanned PDF

A PDF exported as an image has no text for a parser to read. The scan reports it as a blocking defect, and the score is capped at 40.

Example promptWhy does https://r1cco.com/job-kit-ai/samples/scanned.pdf score so low, and how do I fix it?
Match a resume to a job posting

Give the posting as well, and the score comes with a separate alignment percentage. Must-have requirements weigh twice as much as preferences.

Example promptHere is a job posting and my attached resume. Review the resume, list the posting's requirements with the evidence for each, and give me the score and alignment.

FAQ

Does Resume Check store my resume?

No. The file exists only in memory and in a temporary folder for that one request, and the folder is deleted before the response is sent. Logs hold the time, tool, outcome, duration and file size, never the content, file name or link. See the privacy policy.

Why is my score capped at 40?

The resume has a blocking defect: no extractable text, text that is hidden on the page, role headers or dates that extract out of order, or contact details only in a page header or footer. Fix the defects the scan lists first, then review again.

I see "only https URLs are supported" or "private or local address"

The scan fetches only public https links on the default port. Links to a private network, a local machine or plain http are refused before any connection. Attach the file instead, or host it at a public https address.

My Google Drive or Dropbox link returns "unsupported file type"

A share link usually opens a preview page, not the file. Use the provider's direct download link, or attach the file in ChatGPT. Only PDF and DOCX are supported; export other formats to PDF first.

I see "download timed out" or "exceeds the 10 MB download limit"

Each download has 15 seconds and 10 MB. Reduce the file size or host it somewhere faster. Files over 2.5 MB are still scanned, with a file_too_large note.

I see "the server is busy" or a 429 error

The server limits concurrent scans and requests per address so one client cannot crowd out others. Wait a few seconds and try again.

Is the score an employer's ATS score?

No. The rubric is a designed framework for resume quality. It is not any employer's applicant tracking score and does not predict interview outcomes.
