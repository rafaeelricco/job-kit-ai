Resume Check

A remote MCP server that lets an AI assistant check a resume file before you apply. It finds the parsing risks a page view hides and computes the review score with fixed arithmetic, so the number is the same in every assistant.

What it does

Your assistant sends the resume file to Resume Check and gets back a list of risks: no text layer (a scanned page), hidden text, contact details only in a page header or footer, broken or private-use characters, text boxes, tables, images, and a file over 2.5 MB. The assistant then rates the resume against the Job Kit rubric, and Resume Check turns those ratings into a 0 to 100 score. A blocking defect caps the score at 40.

Resume Check does not call an AI model, does not read your accounts, and does not store your file. It accepts PDF and DOCX files up to 10 MB.

Add it to your assistant

Server URL: https://r1cco.com/job-kit-ai/mcp. No sign-in is needed.

Claude

Open Settings → Connectors → Add custom connector, name it Resume Check, paste the server URL and save. Turn it on in a conversation from the tools menu. Custom connectors need a Claude plan that supports them.

ChatGPT

Turn on developer mode in Settings → Apps → Advanced settings, choose Create app, name it Resume Check, paste the server URL and choose no authentication. Select it from the tools menu in a conversation, then attach your resume.

Other MCP clients

Any client that supports Streamable HTTP can connect to the same URL, for example MCP Inspector:

npx @modelcontextprotocol/inspector

Tools

All four tools are read-only.

get_review_rubric

Returns the rubric: seven weighted criteria, the 0 to 4 rating scale, the rule that bullets in the two most recent roles weigh double, the blocking defects and their cap, and posting alignment weights.

What rubric does Resume Check use to rate a resume?

score_resume_review

Takes the assistant's ratings and returns the weighted score, whether the blocking cap applied, how much of the rubric was assessed, and posting alignment when a posting was given.

Score my resume: positioning 3, skills 4, writing 3, parsing 4, and my two recent bullets rate 4 and 3.

scan_resume_url

Downloads a PDF or DOCX from a public https link and returns the parsing risks. Only public addresses are fetched, with a 10 MB and 15 second limit.

Check this resume for parsing problems: https://r1cco.com/job-kit-ai/samples/clean.pdf

scan_resume_file

Scans a resume you attached in ChatGPT and returns the same report.

Limits

The scan reads the text layer. It does not run OCR, so a scanned image resume is reported as having no text. The rubric is a designed framework, not an employer's ATS score or a prediction of interview success. Each client address may make 120 requests per minute.
