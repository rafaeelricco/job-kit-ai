Resume Check

Privacy policy

Resume Check processes a resume only to answer the request that sent it, and keeps nothing afterwards.

What is collected

When an assistant calls a tool, Resume Check receives the tool arguments: rubric ratings, or the link to a resume file. For a scan it downloads that file. It does not ask for your name, account or sign-in.

How it is used

The file is used only to build the scan report returned to your assistant. Ratings are used only to compute the score. Nothing is used for training, profiling, advertising or analytics.

How it is stored

The file and its extracted text exist only in memory and in a temporary folder created for that one request. The folder is deleted before the response is sent, whether the scan succeeds or fails. The download link and file identifier are not stored.

Logs

For each tool call the server logs the time, the tool name, whether it succeeded, how long it took and the file size in bytes. Logs contain no resume text, file name, link or finding. The web server keeps no access log for Resume Check addresses. Your IP address is held in memory only to enforce the rate limit.

Third parties

Resume Check shares nothing with third parties. It contacts only the host in the link your assistant sends, to download the file. Your assistant's provider, for example Anthropic or OpenAI, handles the conversation under its own privacy policy.

Retention

Resume files and their contents: none; they are deleted within the request. Operational logs: kept in the server's system journal and rotated, typically within 30 days.

Contact

Questions or requests: open an issue at github.com/rafaeelricco/job-kit-ai/issues. Do not attach a real resume to an issue.
